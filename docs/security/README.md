# Segurança e privacidade

Modelo de ameaças, controles e decisões de privacidade do ClinicOS.

> Dados de saúde são dados pessoais sensíveis. Este projeto **não declara conformidade com a LGPD**: até haver parecer jurídico e as demais portas de qualidade, use somente dados sintéticos em desenvolvimento, testes e demonstrações.

Para reportar uma vulnerabilidade, abra um aviso de segurança privado no GitHub (aba Security) em vez de uma issue pública.
